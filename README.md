# منيو مطاعم السعودية | KSA Restaurants Menus

دليل شامل لمنيوهات وأسعار مطاعم المملكة العربية السعودية – تحديث يومي

## 📁 هيكل الملفات

```
ksa-restaurants-menus/
├── index.html          ← الصفحة الرئيسية
├── style.css           ← ملف التصميم
├── script.js           ← ملف JavaScript
├── sitemap.xml         ← خريطة الموقع لـ SEO
├── robots.txt          ← ملف Robots
├── ads.txt             ← ملف AdSense
├── README.md           ← هذا الملف
└── pages/
    ├── about.html          ← من نحن
    ├── contact.html        ← اتصل بنا
    ├── privacy-policy.html ← سياسة الخصوصية
    └── terms.html          ← الشروط والأحكام
```

## 🚀 رفع على GitHub Pages

1. أنشئ Repository جديد على GitHub
2. ارفع جميع الملفات كما هي (مع مجلد `pages/`)
3. اذهب إلى **Settings → Pages**
4. اختر **Branch: main** ثم اضغط **Save**
5. انتظر دقيقة ثم سيكون الموقع متاحاً على:
   `https://USERNAME.github.io/REPO-NAME/`
